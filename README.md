# Latin vocab test, Wed 18 Nov

Single file app: `index.html` (22 words, plus verb principal parts and endings). No internet and no login needed once opened.

## Open it
- **Mac / laptop:** double-click `index.html` (opens in Safari or Chrome). Or drag it into a browser window.
- **iPhone:** the Files app's preview does NOT run the app's buttons (Quick Look blocks JavaScript). Open it from a web link instead.

Phone link (open in Safari): https://raw.githack.com/ads4-AI/raven-latin-vocab/main/index.html

Shortcut links: `#type` opens in Type it mode, `#quiz` in Quiz mode, `#parts` in principal parts, `#endings` in verb endings.

## How to use
1. **Flashcards:** say the answer out loud, tap the card (or Space) to flip. "I knew it" (→) or "Still learning" (←). Still-learning cards come back a few cards later and go into ★ Hard ones.
2. **Type it:** type the answer. Macrons and capitals don't matter. For verbs, the first principal part is enough (for example aedifico). Any one of the listed English meanings is enough.
3. **Quiz:** pick 1 of 4 (keys 1-4).
4. **Parts:** drill the three principal parts of the 9 verbs.
5. **Endings:** practise present, imperfect and perfect forms (all six persons). No pluperfect. Type the English (for example "we raised") or swap to EN→LA and type the Latin form. Quiz works here too. Wrong tense or person is marked wrong, not nearly.

- EN→LA / LA→EN swaps direction. ◐ toggles dark mode.
- Progress and ★ Hard ones save on that device/browser.

Suggested tonight: Flashcards on All → Type it on ★ Hard ones → Parts → a run of Endings (present, then perfect, then imperfect).
